# About AntiGolem

**AntiGolem** is a local-first semantic forensics and language-audit toolkit for inspecting wording, ambiguity, framing, responsibility, agency and constructive alternatives across complete texts.

## What it does

AntiGolem analyzes the full detected text sentence by sentence instead of sampling a few examples. Its deterministic engine works without an API key or account, while optional local AI can provide a second opinion or rewrite assistance when a compatible on-device model is available.

Core functions include strict BAD / AMBIVALENT / GOOD / NEUTRAL classification, D-0 / D-1 / D-2+ reference-distance auditing, framing and responsibility heuristics, extended statistics, direct text improvement with Undo, friendly critique generation, native text-file import, Android floating toolkit, and Circle Select region analysis.

## Design principle

The tool is deliberately strict about ambiguous, absolutist, responsibility-diffusing and negative-normalizing wording, but its findings remain editorial heuristics. Labels such as Golem/Pygmalion framing and ghost-context are close-reading aids, not clinical diagnoses or proof of subconscious causation.

## Android

The Android build uses a compact floating toolkit over the launcher and normal apps after the user explicitly enables the AntiGolem accessibility service. Screen text is analyzed only after a visible user action.
