LOCAL AI

API-free local AI strategy

Stage 1 — deterministic engine. The complete sentence-by-sentence audit always works locally without an API key, account or remote inference server.

Stage 2 — browser-provided local model. On compatible browsers/devices AntiGolem can use the browser LanguageModel / Prompt API as an optional second-opinion layer.

Stage 3 — WebLLM/WebGPU fallback. Compatible devices may optionally initialize a compact local model such as Qwen2.5-0.5B-Instruct through WebLLM. Runtime/model files must be downloaded before local inference can run.

Privacy boundary. AntiGolem does not require a paid cloud inference API. The local-model paths are designed so analyzed text remains on-device during inference. External model/runtime files may still need to be downloaded initially.

Compatibility. Local AI availability depends on browser, WebView, WebGPU support, memory and device performance. If unavailable, the deterministic analysis and extended statistics remain fully usable.
