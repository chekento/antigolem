AntiGolem Privacy & Accessibility Disclosure

Local-first analysis. Text pasted into the web application is processed in the browser. AntiGolem has no application backend and does not intentionally transmit the analyzed text to the repository owner.

Optional local LLM. The deterministic audit works without any model download. If the user explicitly starts the Local AI cross-check, AntiGolem first tries the browser-provided LanguageModel. On compatible WebGPU devices it can otherwise load a small Qwen2.5 model through WebLLM. Runtime/model files may be downloaded from third-party hosting and cached locally; AntiGolem does not send the analyzed text to a paid inference API. Third-party hosting may still receive ordinary network metadata associated with downloading those public files.

Android AccessibilityService. The floating toolkit requires the user to manually enable AntiGolem in Android Accessibility settings. When enabled, AntiGolem can read text and content descriptions that the currently active app exposes through the Android accessibility tree. The service exists solely to support user-requested semantic audits.

Circle Select. Circle Select displays a transparent selection overlay and lets the user draw an oval around a screen region. AntiGolem then filters Android accessibility nodes by their on-screen bounds and analyzes only accessible text intersecting that oval. Circle Select itself does not take a screenshot and does not continuously record the screen.

Visible user action. Screen-text capture starts only after an explicit toolkit action. Captured accessibility text is stored only in local app preferences long enough to transfer it into the AntiGolem analysis screen. The current implementation does not upload it to an AntiGolem server.

File import. Text-file import uses Android's system document picker. AntiGolem receives only the file the user explicitly selects.

Limitations. Images, video, canvas-rendered text, protected windows and some PDF/web viewers may expose little or no text through accessibility. AntiGolem does not bypass protected content; those cases may require a future local OCR/screen-capture mode with separate user consent.

Methodology. Golem/Pygmalion, mantra and “programming” labels are rhetorical heuristics, not clinical diagnoses or proof of subconscious/neural causation. Extended indexes are editorial comparison signals, not clinical or causal measurements.

Third parties. GitHub Pages and GitHub Releases are hosted by GitHub. Optional model/runtime downloads can involve the browser vendor, jsDelivr, GitHub-hosted WebLLM assets, or Hugging Face model hosting depending on the selected local-model path. The AntiGolem repository version itself contains no analytics code.
