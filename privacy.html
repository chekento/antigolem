AntiGolem Privacy & Accessibility Disclosure

Local-first analysis. Text pasted into the application is processed locally. AntiGolem has no application inference backend and does not intentionally transmit analyzed text to the repository owner.

Optional local LLM. The deterministic audit works without a model. If the user starts Local AI, AntiGolem first tries a browser-provided on-device LanguageModel. On compatible WebGPU devices it can otherwise load a compact WebLLM model. Runtime/model files can be downloaded from third-party hosting and cached locally; the analyzed text is not sent to a paid AntiGolem inference API.

Android AccessibilityService. The floating toolkit must be manually enabled in Android Accessibility settings. It may read text/content descriptions exposed by the currently active app only to perform user-requested analysis actions.

Freehand Circle Select. Circle Select is a true freehand lasso rather than a resizable oval. The finger path is stored as a polygon, automatically closed when the finger is lifted, and accessibility nodes are selected against that actual drawn shape. Normal Circle Select does not take a screenshot.

Freehand Circle OCR. On Android 11 or newer, the separate explicit Circle OCR action can request a one-shot screenshot through Android's AccessibilityService screenshot capability. AntiGolem hides its own selector, crops to the freehand lasso bounds, masks everything outside the drawn polygon locally, and performs Latin-script text recognition with the bundled on-device ML Kit OCR model. The screenshot is not uploaded by AntiGolem and is released after OCR. Android protected/secure windows cannot be screenshot-scanned.

Quick result overlay. Captured text is temporarily stored in local app preferences so the floating quick-result panel and full analyzer can use the same user-requested capture. The quick panel is a preliminary local estimate; full grounded percentages are computed in the main strict audit.

Document Lab. The user can explicitly select multiple TXT, Markdown, HTML, CSV, JSON, XML, RTF, PDF, DOCX and image files. Plain-text formats are handled directly. PDF.js, Mammoth and Tesseract.js may be downloaded from public CDN hosting on first browser use for PDF, DOCX and browser-side image OCR. Those public runtime downloads can expose ordinary network metadata to their hosts. Document text remains in the local AntiGolem page after the runtime has loaded.

Visible user action. Accessibility capture, screenshot OCR and document import start only after an explicit user action. AntiGolem does not continuously harvest text or record the screen.

Methodology. Golem/Pygmalion, mantra, ghost-context and “programming” labels are rhetorical/editorial heuristics, not clinical diagnoses or proof of subconscious or neural causation. Scores and percentages describe detected wording signals under AntiGolem's rules.

Third parties. GitHub Pages/Releases are hosted by GitHub. Optional local-model or document-runtime downloads can involve browser vendors, jsDelivr, Hugging Face or other public runtime hosting. The repository version contains no analytics code.
