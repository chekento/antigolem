About AntiGolem

AntiGolem is a local-first language auditing tool for full-text semantic and rhetorical analysis. It is designed to help writers inspect ambiguity, reference distance, framing, responsibility diffusion, self-undermining language and constructive alternatives.

The deterministic analysis works without an API key or account. Local AI can be used as an optional second opinion when a compatible on-device/browser model is available.

AntiGolem deliberately separates heuristic editorial signals from scientific or clinical claims. Labels such as Golem/Pygmalion framing and ghost-context are used as close-reading aids, not diagnoses.
